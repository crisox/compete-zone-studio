name: Generation provenance
description: Truthful technical video history despite evolving templates, brand settings and voice instructions.
---

Technical video details must describe the per-run inputs and actual prepared provider requests, not regenerate an old request using today's settings.

**Why:** The user asked to save valuable technical metadata about what was sent to Gemini, accessible from each video in the library. Brand presentation, pronunciation and prompt processing have changed repeatedly; an old creator description alone cannot recover the historical final prompt, speech, references or brand snapshot.

**How to apply:** Capture inputs and final request parameters during generation, before the paid request. Keep historical records explicitly limited when those snapshots are missing. Clearly distinguish requested duration and prepared speech from measured duration and transcribed audio. Exclude credentials and binary image data; reference sizes and hashes are useful without retaining binary payloads. Technical records belong only to the creation's owner.
